# Туториал: Создание приложения-блога

> Пошаговое создание блога с использованием Pristine Framework

## Обзор туториала

В этом туториале мы создадим простое, но полноценное блог-приложение, которое продемонстрирует все основные принципы Clean Architecture. 

### Что мы создадим

📝 **Блог-приложение** включающее:
- Систему пользователей (авторы постов и комментариев)
- Статьи блога с заголовком, содержимым, автором и датой
- Категории для организации постов
- Теги как независимые сущности
- Комментарии к постам
- Use Cases для всех основных операций

### Чему вы научитесь

- ✅ Правильно разделять **Entity** и **Aggregate**
- ✅ Создавать **Value Objects** для типизированных значений
- ✅ Проектировать **Repository** интерфейсы
- ✅ Реализовывать **Use Cases** для бизнес-сценариев
- ✅ Организовывать **доменные события**
- ✅ Структурировать код по **ограниченным контекстам**

## Предварительные требования

### Знания
- Базовое знание PHP 8.0+
- Понимание ООП принципов
- Знакомство с Composer
- Желание изучить Clean Architecture

### Подготовка
1. **Установите Pristine Framework** согласно [руководству по установке](../getting-started.md#установка)
2. **Изучите основные понятия** в [руководстве для начинающих](../getting-started.md#основные-принципы)
3. **Подготовьте рабочую среду** с поддержкой PHP 8.0+
